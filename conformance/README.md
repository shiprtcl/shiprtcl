# Conformance

`fingerprint-vectors.json` holds the SHIPRTCL v0.1 fingerprint vectors (spec §12). Each vector has:

| Field | Meaning |
|---|---|
| `mediaType`, `body` | the raw input |
| `mapHints` | optional contract map hints (§4.4) |
| `canonical` | the exact canonical form (§4.5) |
| `fingerprint` | `sr1:sha256:` + SHA-256 of `canonical` (§4.6) |

An implementation claiming **SHIPRTCL Fingerprint** conformance MUST reproduce `canonical` and `fingerprint` byte for byte for every vector, in every media type it supports.

You can check the hashing step independently of any SHIPRTCL code:

```bash
python3 -c 'import json,hashlib; d=json.load(open("fingerprint-vectors.json")); print(all("sr1:sha256:"+hashlib.sha256(v["canonical"].encode()).hexdigest()==v["fingerprint"] for v in d["vectors"]))'
```

Vectors are generated by `scripts/gen-vectors.mjs`. They change only through a SEP.
